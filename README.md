# Extella package requests

Ask for an open-source browser app on GitHub to be packaged for [Extella](https://extella.dev/apps/) — a free desktop app for macOS and Windows where open-source apps open without a terminal or Docker, and people's files stay on their own computer.

**[Request a package →](https://github.com/AnvarBakiyev/extella-requests/issues/new?template=package-request.yml)**

## What fits

- The project runs in a browser without its own server: the build is static files (Vite, Astro, plain HTML, a static Next.js export and similar).
- It has an open-source license that allows redistribution.
- Apps that need a backend, a database or Docker are not handled here yet.

## What happens after a request

1. We try to package the project and check it in a real Extella window.
2. If you are the author or a maintainer, you see the result first and tell us whether it represents your project correctly.
3. Only then it appears in the Extella store, with your name, your license and a link back to your repository. Every change we make is listed in a file inside the package.
4. If you ever want it changed or removed, comment on your request — we do it the same day.

Requests from people who are not the author are welcome too. We package those only after the author agrees.

Packaging is free. There is no badge or promotion asked of you.
