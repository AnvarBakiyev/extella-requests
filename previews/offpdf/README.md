# OffPDF in Extella (test)

OffPDF 0.4.0 by Mehmetcan Kul and the OffPDF contributors (MIT), https://github.com/McanKul/offpdf. Screenshots of a private test version running inside the Extella window on a Mac with Apple silicon. Not published.

- `00-not-installed.png`: what the window shows on a computer where OffPDF isn't installed yet.
- `01-home.png`: OffPDF's own interface with all 23 tools.
- `02-merge-done.png`: two PDFs merged; the result is saved as a download.
- `03-ocr.png`: OCR with English selected, before the run.
- `EXTELLA_CHANGES.md`: everything that was changed or added to make it run in the window.
